Facebook Platform access from a PHP app

A fork of the open-source Facebook SDK for PHP v3.2.3: log users in, read their profile and make Graph API calls from PHP. Upstream has moved to v4 at facebook/facebook-php-sdk-v4.

$composer require "facebook/php-sdk:@stable"
PHPComposerPHPUnitApache 2.0

Independent fork, not affiliated with or endorsed by Meta. For new projects use the official SDK.

Quick start
require 'facebook-php-sdk/src/facebook.php';

$facebook = new Facebook(array(
  'appId'  => 'YOUR_APP_ID',
  'secret' => 'YOUR_APP_SECRET',
));

$user = $facebook->getUser();
if ($user) {
  $profile = $facebook->api('/me');
}

What it does

User sessions

getUser() returns the logged-in user's ID.

Graph API calls

api('/me') and any HTTP method with parameters.

Login and logout URLs

getLoginUrl() and getLogoutUrl() for the current state.

Full test coverage

PHPUnit suite included in the repository.
